# CiRMessage App

This file contains important commands and instructions to get the app running.

## Instructions
Make sure the ".env" file is there and that "NODE_ENV" is set to production.
Then configure the app with the npm commands "run build/start".

The file contains the following:

\#  --- Express ---  
PORT = 1001

\# --- Dev ---  
NODE_ENV = production

## Commands


### npm

<!-- runs a full build of the project and adds all node_modules -->
- run build

<!-- starts the application -->
- run start
